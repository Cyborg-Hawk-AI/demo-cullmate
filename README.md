# CullMate

> AI culls thousands of wedding RAW photos into a client-ready gallery automatically.

## What is CullMate?

CullMate is built for **Solo and small-studio wedding photographers shooting 20-50 weddings/year who spend 4-8 hours per wedding on manual culling**. None identifiable — this is a commodity feature set already served by multiple funded products with large user bases and proprietary training datasets

### Core MVP features
- Automated RAW ingestion and duplicate grouping
- AI best-shot selection (sharpness, eyes open, expression scoring)
- Client-ready gallery export
- Lightroom/Capture One catalog integration
- Per-wedding processing dashboard

**Pricing:** Flat monthly subscription, unlimited images at $49/month

## The research: why this exists

The user identified a real and well-documented pain: wedding photographers routinely cull 2,000-4,000 RAW files per wedding, taking 4-8 hours manually. Reddit threads confirm this is a 'stab your eyes out' problem. However, the evidence gathered reveals that Aftershoot already solves this problem end-to-end — culling 2,613 RAW files in 18 minutes, grouping duplicates, picking best shots, and creating client galleries. Multiple other competitors (Narrative Select, FilterPixel, Imagen AI) also compete here. The opportunity was real but has already been captured.

## How this business runs itself (mailbox money)

The goal is passive, low-maintenance recurring revenue: AI is how we build and operate the business, not necessarily what it sells.

After launch, file processing is fully async via cloud GPU queues. Stripe handles billing. Onboarding is self-serve. However, maintaining competitive AI model quality requires ongoing training data curation and model updates — this is not a set-and-forget product. Competing on model quality against Aftershoot's years of labeled wedding photography data is a sustained engineering investment, not passive income. Estimated owner hours/week at maturity: 15-20 (mostly model maintenance and customer churn firefighting).

**Estimated owner time:** ~18 hour(s)/week

**MVP estimate:** Python/FastAPI backend + React frontend + cloud GPU inference (AWS/Replicate) + S3 storage; 8-12 weeks minimum, likely 16+ for reliable RAW processing at scale
